# ⚡ RYDR — Ride-Hailing Platform (Ola-style)

> **your city. your ride. zero cap.** 🚕✨

RYDR is a complete Ola/Uber-style ride-hailing platform concept with a Gen-Z aesthetic —
dark mode, neon gradients, glassmorphism, and bold typography.

This repo contains high-fidelity **HTML/CSS/JS frontend prototypes** for every surface of the
platform, plus **complete product documentation** covering every feature required to build
the real thing.

## 🚀 Quick start

No build step. Just open any `.html` file in a browser:

```bash
start index.html
```

Or serve the folder:

```bash
npx serve .
```

## 🎨 Design system

- **Vibe**: dark-first, neon lime `#C8FF2E` + electric violet `#8B5CF6`, glass cards, big rounded corners
- **Type**: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) for display, [Inter](https://fonts.google.com/specimen/Inter) for UI
- **Motion**: soft glows, hover lifts, animated gradients
